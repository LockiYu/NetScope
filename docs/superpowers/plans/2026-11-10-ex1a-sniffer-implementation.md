# 实验 1A 网络嗅探器实施计划

## 执行原则

- 分支：`feat/implementation`，不直接在 `main` 开发。
- 每项功能遵循 RED、GREEN、REFACTOR，并保留对应 Git 检查点。
- 核心库与界面分离，纯解析逻辑不依赖 Qt 控件。
- 单元与集成测试覆盖率目标不低于 80%。
- 每个阶段完成后运行完整测试、ASan 和 UBSan；并发阶段增加 TSan。
- 网络测试显式绕过 HTTP/HTTPS 代理，默认不捕获 `utun`。

## 任务 1 工具链与工程骨架

**用户结果：** 项目可以在当前 Apple Silicon Mac 上配置、编译、测试和启动空白 Qt 窗口。

1. 检测 Homebrew、CMake、Qt 6、Ninja、libpcap SDK 和测试框架。
2. 安装或定位缺失依赖，不替换 macOS 系统 libpcap。
3. 创建根 `CMakeLists.txt`、`src`、`tests/unit`、`tests/integration`、`tests/testdata`。
4. 配置 C++17、严格警告、CTest、GoogleTest、ASan、UBSan、TSan 和覆盖率开关。
5. 添加只验证工程可链接 libpcap 与 Qt 的烟雾测试。
6. 验证 Debug 构建、CTest 和最小应用启动。

## 任务 2 字节读取与协议字段模型

**用户结果：** 所有解析器拥有统一、安全、不会越界的输入和输出结构。

1. RED：测试大小端整数读取、位字段、截断输入和偏移范围。
2. GREEN：实现 `byte_view`、`byte_reader`、`parse_error`。
3. RED：测试 `protocol_field`、`protocol_node` 的嵌套、字节范围和 JSON 导出。
4. GREEN：实现不可变字段模型与结构化错误。
5. REFACTOR：消除重复范围检查，运行 ASan/UBSan。

## 任务 3 基础协议解析

**用户结果：** PCAP 中的 Ethernet、ARP、IPv4/IPv6、ICMP、TCP、UDP 能显示完整首部字段。

1. 分别为 Ethernet/VLAN、ARP、IPv4、IPv6 扩展头编写正常与截断包测试。
2. 实现网络层解析和协议分派。
3. 为 ICMP/ICMPv6、TCP Options、UDP 编写正常、边界和畸形包测试。
4. 实现传输层解析、Flags 展开和字段解释。
5. 添加 IPv4、TCP、UDP、ICMP 校验和测试与实现。
6. 验证 checksum offload 提示不会产生错误结论。

## 任务 4 PCAP 离线读写

**用户结果：** 用户能打开、保存、导出 PCAP，并保留时间戳与捕获长度。

1. RED：用固定 PCAP 样本测试读取包数、时间戳、长度和链路类型。
2. GREEN：实现 RAII `pcap_handle` 与离线读取器。
3. RED：测试全会话、选中包和单流导出后可重新读取。
4. GREEN：实现 PCAP 写入和错误处理。
5. 集成测试取消加载和损坏文件行为。

## 任务 5 单接口实时捕获

**用户结果：** 用户能枚举接口并开始、暂停、恢复和停止实时抓包。

1. 通过抽象后端和 fake pcap 会话测试生命周期、状态机及错误传播。
2. 实现接口枚举、接口分类和默认排除 `utun`。
3. 实现 `pcap_create` 配置、BPF、捕获线程和安全停止。
4. 实现抓包长度、混杂模式、超时和缓冲区配置。
5. 集成测试 `lo0` 捕获；权限不足时验证可操作错误提示。

## 任务 6 多网卡归并与去重

**用户结果：** 用户可以同时捕获多张网卡，数据按时间统一显示且重复包可控。

1. RED：测试跨接口乱序时间戳、相同包、相似包和窗口边界。
2. GREEN：实现每接口捕获会话、归并窗口和短时指纹去重。
3. 实现接口来源集合及关闭去重选项。
4. 压力测试有界队列、应用丢包统计和安全停止。
5. 使用 TSan 验证并发数据结构。

## 任务 7 数据包仓库与基础 Qt 界面

**用户结果：** 用户可以在三栏界面浏览实时或离线数据包。

1. 测试环形容量、淘汰、索引清理和批量发布。
2. 实现不可变 `packet_record`、仓库、基础摘要和按需解析缓存。
3. 创建 Qt 主窗口、捕获工具栏、状态栏和三栏可调布局。
4. 实现绝对时间、默认列、排序、隐藏、重排和列宽持久化。
5. Qt 测试验证选择数据包会更新协议树和 Hex 视图。

## 任务 8 协议树与 Hex 高级交互

**用户结果：** 用户能从字段定位原始字节，也能从字节定位协议字段。

1. 测试嵌套字段中最具体范围查找和重叠范围决策。
2. 实现协议树到 Hex、Hex 到协议树的双向选择。
3. 实现协议层颜色、十六进制和文本搜索、偏移跳转和复制。
4. 实现 1/2/4/8 字节大小端整数解释和范围导出。
5. 实现两个数据包的字节与字段级对比。
6. 实现协议树文本与 JSON 导出。

## 任务 9 过滤、着色、标记与备注

**用户结果：** 用户可以在捕获前后筛选流量，并保存个性化分析状态。

1. 测试 BPF 编译成功、语法错误和过滤历史。
2. 实现捕获过滤输入、快捷项、收藏和错误位置展示。
3. 为显示过滤 tokenizer、parser 和 evaluator 编写测试。
4. 实现字段比较、协议存在性、字符串/数字、逻辑运算和括号。
5. 实现自动补全、后台重过滤、自定义着色、标记和备注。

## 任务 10 反向 DNS 与应用层协议

**用户结果：** 地址可异步显示主机名，DNS、DHCP、HTTP、TLS 显示关键语义。

1. 使用 fake resolver 测试异步命中、正负缓存、TTL、取消和并发去重。
2. 实现后台解析池；列表排序和过滤继续使用原始 IP。
3. 分别为 DNS 压缩名、DHCP Options、HTTP/1.x、TLS Handshake 编写测试。
4. 实现端口加内容特征识别及启发式识别提示。
5. 测试未知载荷和不完整应用消息的安全降级。

## 任务 11 分片与 TCP 重组

**用户结果：** 跨包协议消息可以重组，乱序或缺包时给出明确状态。

1. 测试 IPv4/IPv6 正常分片、乱序、重复、重叠和超时。
2. 实现分片重组、容量上限和清理。
3. 测试 TCP 双向序列空间、回绕、重传、重叠、缺口、FIN 和 RST。
4. 实现有界 TCP 字节流重组。
5. 在连续字节上启用跨包 HTTP/TLS 解析。

## 任务 12 TCP 流与统计视图

**用户结果：** 用户可以查看连接状态、性能指标、时序图和流量统计。

1. 测试规范化五元组、状态迁移、RTT、重传、乱序和重复 ACK。
2. 实现双向流仓库和流生命周期。
3. 实现流包列表、文本/Hex、单流导出和流过滤器。
4. 实现 SYN/ACK/数据/FIN/RST 时序图。
5. 实现协议占比、速率、包长、Top 主机、端口和流统计。

## 任务 13 异常规则与高级界面功能

**用户结果：** 用户能看到可解释、可配置且不夸大结论的流量提示。

1. 为端口扫描、半连接、异常重传、明文认证字段和畸形包编写测试。
2. 实现规则窗口、阈值、触发证据和关闭选项。
3. 实现右键创建过滤器、复制字段、打开关联流和 DNS 会话。
4. 完成协议颜色、浅色/深色主题和界面可访问性检查。
5. 确保敏感载荷不会被日志或异常视图额外持久化。

## 任务 14 系统验证与交付准备

**用户结果：** 软件具备可复现的质量证据，并可用于报告和演示视频。

1. 运行完整 CTest、覆盖率、ASan、UBSan 和 TSan。
2. 使用正常、截断、畸形和大体量 PCAP 回归测试。
3. 在 `lo0` 和默认物理网络接口执行直接网络集成测试。
4. 记录包数、丢包、峰值内存、吞吐和 GUI 响应。
5. 写入 TDD 证据、构建说明、演示脚本和已知限制。
6. 核对最终目录、源码、视频、报告和 Git 链接要求。

## 暂留判定

只有设计文档规定的高级功能可以暂留。暂留必须包含失败样本、已尝试方案、接口状态和不影响基础功能的证据。基础捕获、基础协议、BPF、三栏 GUI、字段联动、多网卡和 TCP 五元组流追踪不得暂留。
